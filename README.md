# ANB Android Recovery Tool

Authorized Android repair assistant starter project.

Features: local device diagnostics, explicit customer authorization, local repair summaries, official recovery guidance, and GitHub Actions APK builds.

Safety: this app does not bypass screen locks, device encryption, Google FRP, or account protections. It does not collect credentials or upload device data.

Build: push to `main`, then open **Actions → Android CI Build**. After a successful run, download `ANB-Android-Recovery-debug-apk`, extract `app-debug.apk`, and install it on a test phone.
