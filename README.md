# ANB Mobile Repair Studio

Professional Android mobile repair shop assistant.

## Shop Edition

A clean, professional workspace for authorized mobile repair services.

### Main Features

- Professional repair studio dashboard
- Redmi, OPPO, Samsung and Vivo brand sections
- USB device scanner
- Connected device information
- Basic Android diagnostics
- Customer-authorized repair records
- Technician notes
- Local repair summaries
- Privacy-aware report sharing
- Official manufacturer recovery guidance

### Supported Workflows

- Device inspection and diagnostics
- Customer-authorized software service
- Official manufacturer recovery
- Manufacturer-supported factory reset guidance
- Repair documentation

### Important Safety Limits

This application does not bypass screen locks, PINs,
patterns, device encryption, Google FRP or account verification.

It does not extract private customer data or collect
device passwords.

Factory reset and wipe operations can permanently erase
customer data. Always obtain explicit authorization and
explain the consequences before proceeding.

USB detection does not mean that the application can
control every connected phone.

### Build

APK builds are intended to run through GitHub Actions.

1. Push changes to the main branch.
2. Open the repository Actions tab.
3. Run the Android CI Build workflow.
4. Check the build and test results.
5. Download the APK artifact only after a successful build.

Do not claim a successful build until GitHub Actions
confirms it.
